这里的“不同沉淀模式”可以分成两层来理解：**成核/反应发生在哪里**，以及 **沉淀后会不会造成堵塞**。这两个概念容易混在一起，拆开就清楚了。

## 1. 均质成核 vs 异质成核：区别在“在哪里开始长晶体”

**均质成核**是在溶液内部自己形成 BaSO₄ 晶核。也就是说，Ba²⁺ 和 SO₄²⁻ 在水体中混合后，溶液内部局部过饱和，晶核直接在液相里出现。这个过程不依赖壁面，但能垒通常比较高，所以需要更强的过饱和条件。

**异质成核/表面沉淀**是在已有固体表面上形成晶核，比如微通道壁面。壁面相当于给晶体提供了“落脚点”，降低了成核能垒，所以更容易发生。补充材料里用 CNT 计算说明，在这篇论文的饱和指数范围 (SI=2.5\sim3.27) 内，异质成核明显主导均质成核。 

所以这篇文章真正重点不是“溶液里到处析出晶体”，而是：**反应物如何被流场带到通道壁面，然后在壁面形成沉淀**。主文也说，在他们使用的 Ba 和 sulfate 浓度下，没有观察到明显的 bulk solution homogeneous nucleation，沉淀主要发生在 channel surfaces 上。

---

## 2. 低 Re 模式：薄层界面沉淀，但不快速堵塞

在低 Reynolds number，比如 Re = 10 时，流动接近二维，两个溶液主要沿着混合界面接触。这个时候沉淀会形成一条**薄而致密的 BaSO₄ 层**，沿着混合界面生长。

它看起来像是“有沉淀”，但它反而会把两种溶液隔开，让后续混合变弱。论文里说 Re = 10 时形成 thin precipitate barrier，阻断混合；荧光示踪实验也显示示踪剂无法穿过这个沉淀层，说明这个层比较致密、近似不可渗透。

这个模式的关键特点是：

| 特征     | 低 Re 薄层沉淀   |
| ------ | ----------- |
| 流动形态   | 接近二维层流      |
| 反应位置   | 主要沿混合界面     |
| 沉淀形态   | 细长、薄、致密     |
| 对混合的影响 | 形成屏障，阻止后续混合 |
| 对堵塞的影响 | 不会快速堵满整个交叉口 |
| 典型 Re  | Re ≈ 10     |

简单说：**它沉淀了，但沉淀得太集中，反而把反应“自我关停”了。**

---

## 3. 中等 Re 模式：惯性过渡沉淀，反应区开始扩大

当 Re 增加到 30、50 左右时，流动不再是简单二维。开始出现 z 方向速度、Dean flow 和局部三维流动。反应物不仅沿着中间混合界面走，还会被带向上下壁面。

结果就是沉淀区域变宽，不再只是一条细线。论文中描述 Re = 30 时，沿混合界面和下游通道的沉淀范围明显扩大；补充材料 Fig. S10 把这个状态称为 **inertial transitional regime**：反应区比 no-clogging 状态明显扩大，但还没有覆盖整个 throat。 

这个模式的关键特点是：

| 特征     | 惯性过渡沉淀                |
| ------ | --------------------- |
| 流动形态   | 二维向三维过渡               |
| 反应位置   | 混合界面 + 部分上下壁面         |
| 沉淀形态   | 区域扩展，但未完全覆盖喉道         |
| 对混合的影响 | 三维流增强反应物表面可及性         |
| 对堵塞的影响 | 有堵塞趋势，但未进入快速堵塞        |
| 典型 Re  | Re ≈ 30–50，具体还受 AR 影响 |

简单说：**这个阶段是“沉淀开始铺开，但还没完全堵死”。**

---

## 4. 高 Re 模式：三维惯性流导致快速堵塞

当 Re > 50，尤其 Re = 100、150 时，Dean flow、recirculation flow 和 z 向速度明显增强。反应物被三维流带到整个交叉口和上下壁面，导致 (\Omega_{\mathrm{Surf}}) 显著提高，表面沉淀范围大幅扩大。

论文说 Re > 50 时，沉淀局部集中在 intersection，并覆盖整个交叉口区域；Re = 150 时，水力传导率快速下降，73 min 时已经降到 0.33，并且交叉口和喉道出现显著堵塞。 

这个模式的关键特点是：

| 特征     | 高 Re 快速堵塞            |
| ------ | -------------------- |
| 流动形态   | 明显三维惯性流              |
| 反应位置   | 整个交叉口、上下壁面、喉道        |
| 沉淀形态   | 大面积、局部集中、快速填充        |
| 对混合的影响 | 强烈增强混合和表面可及性         |
| 对堵塞的影响 | 快速降低水力传导率            |
| 典型 Re  | Re > 50，Re = 150 最明显 |

简单说：**高 Re 下不是简单“冲得快所以不沉淀”，而是三维流把反应物不断送到壁面，导致更快、更大范围的表面沉淀。**

---

## 5. 三种堵塞/沉淀 regime 的核心区别

论文最终把它概括成三个 regime：

| 模式                    | 主要控制              | 反应区分布                | 结果                |
| --------------------- | ----------------- | -------------------- | ----------------- |
| No clogging           | 低 Re，非惯性层流        | 反应限制在喉道一侧或混合界面附近     | 形成薄层屏障，沉淀关停，不快速堵塞 |
| Inertial transitional | 中等 Re，三维流开始出现     | 反应区扩大，但没有覆盖整个 throat | 有明显沉淀扩展，但未完全快速堵塞  |
| Rapid clogging        | 高 Re 或低 AR，强三维惯性流 | 反应速率在整个 throat 都有非零值 | 整个喉道/交叉口沉淀，快速堵塞   |

补充材料 Fig. S10 明确说：no clogging regime 中反应 confined to one side of the throat；rapid clogging regime 中整个 throat 都有不可忽略的反应速率；inertial transitional regime 则是反应区扩大但还没有覆盖整个 throat。

---

## 6. 用一句话抓住本质

这篇文章的核心不是说“Re 越大反应越快”这么简单，而是：

**Re 增大 → 三维惯性流增强 → 反应物更容易接触上下壁面 → 表面饱和比 (\Omega_{\mathrm{Surf}}) 增大 → 表面沉淀区域扩大 → 从薄层沉淀转变为快速堵塞。**

最妙的地方在于：**低 Re 也会沉淀，但它是“自我封闭型沉淀”；高 Re 的沉淀是“扩散铺展型沉淀”，所以更容易堵塞。**
